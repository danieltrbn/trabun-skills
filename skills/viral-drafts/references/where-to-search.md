# where-to-search.md — где искать и как проверять окно

Запас мест для `$DATA/shelves.md`. На онбординге из них, из раздела «Под тему и регион» и из знаний о теме собирается список автора — ходить по нему, а этот файл — запас. Списки по полкам ниже — англоязычные и с уклоном в интернет и технологии: бери их, если тема такая или аудитория читает по-английски. Для остального главный раздел — «Под тему и регион».

Веб-поиск — только чтобы понять, куда идти. Цифры (просмотры, лайки, очки) — со страницы первоисточника. Место не открылось — записать в воронку «не открылось: место — причина» и идти дальше.

## Сигнал «разлетелось» — для всех полок

- **Reddit.** Без входа JSON-выдача часто закрыта (403). Через браузер с открытой вкладкой `www.reddit.com`: страница `https://www.reddit.com/r/<саб>/top/?t=week`. Если нужен список целиком, из этой вкладки работает `fetch('/svc/shreddit/community-more-posts/top/?t=WEEK&name=<саб>&feedLength=3&after=')` и разбор элементов `shreddit-post` (атрибуты `score`, `post-title`, `content-href`, `permalink`).
- **X.** Поиск `x.com/search?q=<запрос> min_faves:5000 since:<дата − 7 дней>&f=top`. Нужен браузер, где автор вошёл в X.
- **Threads.** `threads.com/search?q=<запрос>`, вкладка «Популярное». Нужен вход.
- **Hacker News.** `news.ycombinator.com/best` и `news.ycombinator.com/show` — открываются без входа.
- **YouTube.** Поиск с фильтром «за неделю», сортировка по просмотрам.
- **Telegram (русскоязычная аудитория).** Каталог tgstat.ru: поиск по публикациям, если есть доступ; иначе — телеграм-каналы, которые автор читает сам.

## Под тему и регион

Сначала спроси себя: где люди из аудитории автора сами узнают новое по этой теме и что они пересылают друг другу. Туда и иди. Для русскоязычной аудитории обычно это:

- телеграм-каналы ниши и города (найти через каталог tgstat.ru и поиск по названию темы);
- VK: сообщества темы и городские паблики — у них видны лайки и репосты;
- Дзен и YouTube: сортировка по просмотрам за неделю;
- Pikabu — для полки 3, абсурдных историй, у постов виден рейтинг;
- профильные медиа и сайты темы (для кулинарии — сайты рецептов, гастро-медиа, обзоры ресторанов);
- городские медиа и афиши — для полки 2, когда аудитория живёт в одном городе;
- Instagram и TikTok по хэштегам темы — через браузер, где автор вошёл.

Для полки 2 составь список имён: 10–30 брендов, мест, людей, мемов, которые знает каждый в аудитории (для домашней кухни в Казани — местные сети, рынки, блюда, известные шефы города).

Порог «разлетелось» подбирай под нишу: для массовой темы — тысячи лайков, для узкой — сотни. Запиши выбранный порог в `shelves.md`.

## Полка 1. Можно сделать сразу

Что держать в голове: вещь, с которой читатель что-то сделает сегодня вечером, — сыграет, посмотрит, попробует, применит, приготовит, купит.

- Reddit: `r/InternetIsBeautiful`, `r/WebGames`, `r/SideProject`, плюс профильные сабреддиты темы с фильтром по «I made», «tool», «guide».
- Hacker News: «Show HN» с сотнями очков.
- itch.io: `itch.io/games/new-and-popular/platform-web` — браузерные игры.
- Product Hunt: топ недели, только то, чем пользуется обычный человек.
- Кино и сериалы на выходные: `top10.netflix.com`, `letterboxd.com/films/popular/this/week/` (обычно только через браузер), онлайн-премьеры недели в регионе аудитории.
- X и Threads: запросы `"I made"`, `"I built"`, `"you can now"`, `"free tool"` плюс слово темы — с порогом лайков.

Проверка: открывается ли из региона аудитории без VPN и регистрации, сколько времени занимает (минута, вечер).

## Полка 2. Своё и узнаваемое

Что держать в голове: бренд, город, школа, мем, человек, которых знает каждый в аудитории автора, сделал что-то смешное, странное или неожиданно человеческое — и это пересекается с темой автора.

- Список имён из `shelves.md`: по каждому — поиск новостей за 7 дней с ключевым словом темы.
- Отраслевые медиа о маркетинге и брендах в регионе аудитории.
- Сами каналы и аккаунты брендов: если случай нашёлся — взять оттуда первоисточник и цитату.
- Каналы и профили, которые читает сам автор: если площадка позволяет выгрузить подписки (например, Telegram Web в браузере), отсортировать посты за 7 дней по просмотрам с фильтром по словам темы. Заодно видно, что у аудитории уже везде.

Проверка: узнает ли бренд человек из аудитории, далёкий от профессии автора.

## Полка 3. Абсурдная реальная история

Что держать в голове: случай, который звучит как выдумка, с деталью для пересказа за ужином.

- Reddit: `r/nottheonion`, `r/offbeat`, профильные сабреддиты темы — топ недели.
- X: слово темы с порогом лайков за неделю.
- Новостные агрегаторы с сортировкой по популярности.

Проверка: деталь подтверждается первоисточником (суд, компания, автор, исследование), а не пересказом. Нет первоисточника — не берём.

## Полка 4. Про жизнь читателя

Что держать в голове: слово, схема или список, в котором читатель узнаёт себя или тех, кому перешлёт, — коллег, семью, друзей. Для рабочей темы это коллеги, для домашней — мама, подруга, семейный чат. Одно новое слово без списка, по которому читатель себя узнаёт, пересылают заметно реже.

- Издания про поведение и культуру: The Cut, Vox, Dazed, The Atlantic, профильные медиа региона аудитории — свежие тексты с новым словом.
- Рассылки, где рождаются слова: Substack и аналоги по теме.
- X и LinkedIn: эссе и схемы про работу, которые разлетелись, — запросы вроде `"there will only be"`, `-maxxing`, `"new job title"` плюс слово темы.

Проверка: можно ли переслать тому, о ком это, со словами «это же мы» или «это же ты».

## Окно: уже везде у аудитории или ещё нет

Смотрим на финалистов, а не на всех. Запрос — название вещи или ключевая фраза на языке аудитории, период — 14 дней.

| Площадка автора | Как проверить |
|---|---|
| Telegram | tgstat.ru → поиск по публикациям (часть функций платная). Есть браузер с Telegram Web — глобальный поиск по публичным постам; у Telegram он ограничен по числу бесплатных запросов в сутки, дальше платно — платное без автора не трогать |
| Instagram, Threads | только через браузер, где автор вошёл: поиск по слову и хэштегу. Фильтра по датам нет — смотри даты верхних постов вручную. Число подписчиков у авторов видно в их профиле. Нет входа — «не проверено» |
| X | `x.com/search?q=<запрос> lang:<язык>&f=top` за 14 дней |
| LinkedIn, блоги, рассылки | веб-поиск на языке аудитории за 14 дней, затем открыть первые результаты |

Как читать результат:

- три и больше публикаций у авторов крупнее автора — окно закрыто;
- одна-две — окно открыто, но в посте нужен свой угол;
- ноль — окно открыто.

Проверить не вышло (нет доступа, кончились запросы) — в оценке «Окно» ставится 1 и пометка «не проверено», а не 2.

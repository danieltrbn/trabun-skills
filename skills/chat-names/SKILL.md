# Названия и группы чатов

Через неделю работы в сайдбаре сорок чатов с названиями вроде «Помощь с задачей» и «Новый разговор»,
и нужный приходится искать по памяти. Скилл делает так, чтобы порядок наводился сам: Claude в первом
же ответе даёт чату название по формату пользователя и кладёт его в группу.

## Где работает

Только во вкладке **Code** десктопного приложения Claude (Mac и Windows). Переименовывать чаты
и двигать их по группам там позволяют встроенные инструменты приложения. В обычном чате claude.ai,
в терминальном Claude Code и в IDE этих инструментов нет — скажи об этом прямо и не обещай.

Инструменты отложенные — перед первым вызовом подгрузи их одним запросом через ToolSearch:
`select:mcp__ccd_session_mgmt__set_session_title,mcp__ccd_sidebar__list_groups,mcp__ccd_sidebar__move_sessions,mcp__ccd_sidebar__create_group,mcp__ccd_sidebar__delete_group`.
Не нашлись — значит, это не вкладка Code; см. абзац выше.

## Почему правило живёт в CLAUDE.md, а не только в скилле

Скилл сам по себе не просыпается в каждом новом чате: Claude зовёт его, когда видит подходящую просьбу.
А «назови чат» никто в начале каждого чата писать не будет. Глобальный `~/.claude/CLAUDE.md` Claude
читает при старте любого чата в любой папке. Поэтому скилл — установщик: он один раз пишет правило
туда, дальше работает правило.

## Установка

1. **Формат названия.** Предложи формат автора и спроси, оставить или поменять:
   `дд.мм | задача | проект`, всё с маленьких букв. Пример: `08.10 | презентация для клиента | ребрендинг кофейни`.
   Дата — день создания чата, задача — суть в два-четыре слова, проект — клиент или проект
   человеческими словами, а если проекта нет — область: работа, блог, учёба, личное.
   Пользователь назвал свой формат — бери его дословно и покажи пример на текущем чате.
2. **Группы.** Покажи список `list_groups` одной строкой на группу: имя и сколько чатов.
   Подсвети пустые группы и группы с одинаковыми именами — с дублями Claude будет раскладывать наугад.
   Предложи удалить пустые и свести дубли. Удаляй только то, на что пользователь ответил «да».
3. **Правило.** Прочитай `~/.claude/CLAUDE.md`. Файла нет — создай. Есть — допиши раздел в конец,
   ничего в нём не трогая. Раздел «Название и группа чата» там уже есть — покажи старый и новый
   вариант и замени только после «да». Текст раздела — ниже, с форматом пользователя.
4. **Проверка.** Примени правило к текущему чату: переименуй его и положи в группу.
   Так пользователь сразу видит результат, а не верит на слово.
5. **Отчёт.** Три строки: где лежит правило, что удалено из групп, как теперь называется этот чат.
   И одна строка о том, что правило заработает с первого ответа в следующем новом чате.

## Текст раздела для CLAUDE.md

Подставь формат и пример пользователя. Остальное оставь как есть.

```markdown
# Название и группа чата

Действует в каждом чате вкладки Code, в любой папке.

- В первом ответе нового чата переименуй его (`set_session_title`, `self`)
  по формату `<формат>`.
  Пример: `<пример>`.
- Дата — день создания чата. Задача — суть в два-четыре слова.
  Проект — клиент или проект человеческими словами; если проекта нет —
  область: работа, блог, учёба, личное.
- Задача по ходу чата сменилась целиком — переименуй, дату не трогай.
- В том же первом ответе положи чат в группу сайдбара: сверь задачу
  со списком `list_groups` и перенеси `move_sessions` с `self`.
- Задача не вписывается ни в одну группу — не клади наугад и не заводи
  группу сам: предложи название новой группы и жди ответа.
```

## Разовые просьбы

- **«Назови этот чат»** — переименуй текущий по формату из `~/.claude/CLAUDE.md`. Формата там нет —
  возьми формат автора и предложи поставить правило насовсем.
- **«Разложи этот чат»** — сверь задачу с `list_groups`, перенеси. Не вписывается — предложи
  название новой группы; заведи её через `create_group` только после «да».
- **«Почисти группы»** — шаг 2 установки без остального.

## Подводные камни

- **Счётчик группы не видит архив.** `session_count` в `list_groups` считает только активные чаты.
  Группа с нулём может держать архивные чаты — при удалении они выпадут в «без группы», и найти
  потом, откуда они выпали, уже нельзя. Перед удалением предупреди об этом одной строкой.
- **Своё название пользователя.** Если пользователь переименовал чат сам, приложение спросит
  разрешения заменить название. Это нормально, не обходи.
- **Не заводи группы сам.** Имена групп — личная система пользователя. Новая группа появляется
  только по его «да».
- **Короткие вопросы.** На «что значит X» легко ответить и забыть про название. Правило про
  первый ответ — значит, и такой ответ начинается с переименования.
- **Не применяй задним числом без спроса.** Старые чаты переименовывай и двигай, только если
  пользователь об этом попросил.

# Правки в древе

`tree.py apply <старая версия> <правки.json> <новая версия>`. Файл правок:

```json
{
  "sources": {
    "r1_m1": {"title": "Метрическая книга церкви такой-то, 1861, рождение", "ref": "Госархив области, ф. 1, оп. 1, д. 2, л. 15", "url": "https://...", "label": "скан"},
    "r1_i1": {"title": "Интервью с бабушкой, 12.03.2026, 0:14:20", "label": "интервью"}
  },
  "ops": [
    {"op": "add_person", "id": "p_ivan", "name": "Иван Петрович /Сидоров/", "sex": "M", "birth": {"date": "3 JUN 1861", "place": "д. Берёзовка"}, "src": "r1_m1", "note": "Запись читалась с трудом"},
    {"op": "add_family", "id": "f_ivan", "husb": "p_ivan", "wife": "I12", "children": ["I3"], "marr": {"date": "1885"}, "src": "r1_m1"},
    {"op": "add_child", "family": "F4", "child": "p_ivan", "src": "r1_m1"},
    {"op": "set", "who": "I3", "field": "birth.date", "value": "ABT 1869", "src": "r1_m1"},
    {"op": "set", "who": "I3", "field": "name", "value": "Мария /Сидорова/", "src": "r1_m1"},
    {"op": "set_marriage", "family": "F4", "marr": {"date": "12 FEB 1890", "place": "Псков"}, "src": "r1_m1"},
    {"op": "note", "who": "I3", "text": "По рассказу дочери, ушла из дома в 1920-м.", "src": "r1_i1"},
    {"op": "event", "who": "I3", "type": "OCCU", "date": "1910", "place": "Москва", "note": "ткачиха", "src": "r1_m1"},
    {"op": "cite", "who": "I3", "src": "r1_m1"},
    {"op": "detach", "child": "I8", "family": "F2", "why": "Отчество не сходится, запись другой семьи"},
    {"op": "merge", "keep": "I4", "drop": "I11", "why": "Один человек: имя, год, деревня"},
    {"op": "remove_person", "who": "I12", "why": "Чужой тёзка, вошёл из чужого древа"}
  ]
}
```

Правила:

- `label` один из: `скан`, `индекс`, `публикация`, `интервью`, `семейное`, `чужое древо`, `вывод`.
- `src` обязателен у всего, что добавляет или меняет данные. `why` обязателен у `detach`, `merge`, `remove_person`.
- Id в правке можно придумать свои, латиницей. У существующих людей смотри id в отчёте `audit` в квадратных скобках.
- `field` бывает `name`, `sex`, `birth.date`, `birth.place`, `death.date`, `death.place`.
- Типы `event`: `RESI` где жил, `OCCU` занятие, `EMIG` выезд, `IMMI` въезд, `MILI` служба, `CENS` перепись, `EDUC` учёба, `RELI` вера, `BURI` похороны, `EVEN` прочее.
- Снятое не пропадает: `detach`, `merge` и `remove_person` кладут запись в раздел `detached` версии, вернуть можно по нему.
- Имя в формате GEDCOM: фамилия между косых черт.
- Версии: `tree_v1.json`, `tree_v2.json`. Перезаписать нельзя, для правки ошибки возьми следующий номер.
